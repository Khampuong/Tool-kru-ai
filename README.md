# Tool-kru-ai — ระบบประเมินเครื่องมือวิจัยโดยผู้เชี่ยวชาญ

ระบบเว็บสำหรับให้ผู้เชี่ยวชาญประเมินเครื่องมือวิจัย (IOC และความเหมาะสม 5 ระดับ) เขียนความคิดเห็น และลงนามอิเล็กทรอนิกส์
แล้วคำนวณผลตามหลักการวิจัยโดยอัตโนมัติ ข้อมูลตั้งต้นนำมาจากแบบประเมิน 7 ชุดในโฟลเดอร์ `Tool-research/`

## การติดตั้งและเปิดใช้งาน

ต้องมี Node.js 22.13 ขึ้นไป

```bash
npm install
npm start            # เปิดที่ http://localhost:3000/
```

หน้าเข้าระบบ “การประเมินเครื่องมือ” มี 2 แท็บ:

- **ผู้เชี่ยวชาญ** — เข้าด้วย **อีเมลหรือเบอร์โทรศัพท์ 10 หลัก** และรหัสผ่าน
  - ครั้งแรก (วิธีที่ 1): หน้าแรก → **“คลิกกรอกข้อมูลเพื่อเข้าสู่ระบบ”** → เลือกชื่อ → กรอกอีเมล เบอร์โทรศัพท์ ตั้งรหัสผ่าน → **บันทึก** → เข้าสู่ระบบอีกครั้ง
    (รายชื่อแสดงเฉพาะผู้ที่ยังไม่มีบัญชี เมื่อลงทะเบียนแล้วชื่อจะหายจากรายการ)
  - ครั้งแรก (วิธีที่ 2): เปิด **ลิงก์เฉพาะบุคคล** ที่ผู้วิจัยส่งให้ → ระบบให้กรอกอีเมล เบอร์โทรศัพท์ ตั้งรหัสผ่าน และยินยอมการเก็บข้อมูล ก่อนเข้าแบบประเมิน
  - หรือผู้ดูแลสร้างรหัสให้ (หน้า “ผู้เชี่ยวชาญ” → “ตั้งรหัสเข้าระบบ”) ซึ่งผู้ดูแลเรียกดูซ้ำได้ด้วยปุ่ม “ดูรหัส”
  - เมื่อเข้าแล้วจะเห็นรายการแบบประเมินที่ได้รับมอบหมาย เริ่ม/ทำต่อ/ดาวน์โหลดฉบับที่ลงนามได้ และเปลี่ยนรหัสผ่านเองได้
  - การตอบ ส่ง และดาวน์โหลดแบบประเมินต้องเข้าสู่ระบบก่อนเสมอ (ผู้ที่ได้ลิงก์ไปแต่ไม่มีรหัสเข้าไม่ได้)
- **ผู้ดูแลระบบ (Admin)** — เข้าด้วยรหัสผ่านผู้ดูแล

- ครั้งแรกระบบจะสร้างรหัสผ่านผู้ดูแลแบบสุ่ม แสดงในหน้าจอและบันทึกไว้ที่ `data/ADMIN_PASSWORD.txt` (เปลี่ยนได้ในหน้า “ตั้งค่า”)
- หรือกำหนดเองด้วยตัวแปร `ADMIN_PASSWORD=...`  พอร์ตกำหนดด้วย `PORT=...`
- ข้อมูลทั้งหมดอยู่ในไฟล์ `data/eval.sqlite` (สำรองได้โดยคัดลอกไฟล์ หรือดาวน์โหลด JSON ในหน้าตั้งค่า)
- หากนำขึ้นเซิร์ฟเวอร์จริงหลัง reverse proxy ให้ตั้ง `TRUST_PROXY=1` และใช้ HTTPS

## ขั้นตอนการใช้งาน

1. **ผู้เชี่ยวชาญ** → เพิ่มรายชื่อทีละคน หรือ **“⬆ นำเข้าจาก Excel”** (.xlsx/.csv)
   - ระบบหาหัวตารางอัตโนมัติ แปลงรหัสความเชี่ยวชาญ (เช่น D1–D5) ตามตารางคำอธิบายในไฟล์
   - แยกอีเมล / เบอร์โทร 10 หลัก / ลิงก์อื่น ๆ (เก็บในหมายเหตุ) ออกจากช่องทางการติดต่อ
   - แสดงตัวอย่างก่อนนำเข้า และข้ามรายชื่อที่ซ้ำกับในระบบ
   - เบอร์โทรศัพท์ต้องเป็นตัวเลข 10 หลัก
2. เลือก **ชุดเครื่องมือ** ให้ผู้เชี่ยวชาญได้ 2 ทาง: ในหน้าแก้ไขผู้เชี่ยวชาญ (ติ๊กเลือกหลายชุด)
   หรือ **แบบประเมิน** → เลือกชุด → แท็บ “ผู้ประเมิน & ลิงก์” → เพิ่มผู้ประเมิน (1 ชุดมีผู้ประเมินได้หลายคน)
3. ส่งให้ผู้เชี่ยวชาญด้วยวิธีใดวิธีหนึ่ง: คัดลอก **ลิงก์เฉพาะบุคคล** หรือ **ตั้งรหัสเข้าระบบ** (ต้องมีอีเมล) แล้วคัดลอกข้อความเชิญที่ระบบสร้างให้
4. ผู้เชี่ยวชาญกรอกตอนที่ 1–3 เขียนความคิดเห็นรายข้อ (💬) / รายส่วน / ภาพรวม ระบบบันทึกร่างอัตโนมัติ
5. ผู้เชี่ยวชาญ **ลงลายมือชื่อบนจอ** (เมาส์/นิ้ว/ปากกา) ยืนยัน แล้วส่ง — ระบบตรวจว่าตอบครบทุกข้อก่อน
6. แท็บ **“ผลการวิเคราะห์”** แสดง IOC, x̄, S.D., ระดับ, ผ่าน/ไม่ผ่าน รายข้อ รายด้าน รายส่วน และภาพรวม

## การส่งออกไฟล์

| เอกสาร | Excel (.xlsx) | Word (.docx) | PDF |
|---|---|---|---|
| แบบประเมินที่กรอกแล้ว (รายคน พร้อมลายเซ็น) | ✓ | ✓ | พิมพ์ → บันทึกเป็น PDF |
| ผลการวิเคราะห์ | ✓ 5 แผ่นงาน: สรุปผล, IOC รายคน, คะแนนรายคน, ข้อมูลดิบ (SPSS), ความคิดเห็น | ✓ ตารางพร้อมใส่วิทยานิพนธ์ | พิมพ์ → บันทึกเป็น PDF |

ไฟล์ Word/Excel ใช้ฟอนต์ TH Sarabun New ขนาด 16 PDF ใช้การพิมพ์จากเบราว์เซอร์เพื่อให้สระและวรรณยุกต์ภาษาไทยแสดงถูกต้อง

## สูตรที่ใช้คำนวณ (`lib/stats.js`)

- **IOC = ΣR / N** (Rovinelli & Hambleton) — เกณฑ์ IOC ≥ 0.50
- **x̄ = Σx / n**, **S.D. = √[Σ(x − x̄)² / (n − 1)]** (เท่ากับ STDEV.S ของ Excel และ SPSS)
- แปลความหมาย (บุญชม ศรีสะอาด, 2545): 4.51–5.00 มากที่สุด · 3.51–4.50 มาก · 2.51–3.50 ปานกลาง · 1.51–2.50 น้อย · 1.00–1.50 น้อยที่สุด
  ใช้ค่าที่ปัดทศนิยม 2 ตำแหน่งในการแปลผล เพื่อให้ตัวเลขที่แสดงกับระดับตรงกันเสมอ
- เกณฑ์ผ่าน: x̄ ≥ 3.51 และ S.D. ≤ 1.00 (ปรับได้ทั้งหมดในหน้าตั้งค่า)
- ค่ารวมรายด้าน/ภาพรวม เลือกได้ 2 วิธี: ค่าเฉลี่ยรายบุคคลก่อน (ค่าตั้งต้น) หรือรวมคะแนนดิบทุกค่า — x̄ เท่ากัน ต่างกันที่ S.D.

ทดสอบการคำนวณด้วย `npm test`

## การแก้ไขข้อมูลโดยผู้ดูแล และความถูกต้องของลายมือชื่อ

- แก้ไขชื่อแบบประเมิน มาตรวัด ส่วน/ด้าน/ข้อ ไฟล์ภาพประกอบ ข้อมูลผู้เชี่ยวชาญ และเกณฑ์ได้ทั้งหมด
- ผู้ดูแลแก้คำตอบของผู้เชี่ยวชาญได้ (ปุ่ม “ดู/แก้ไข”) โดยต้องระบุเหตุผล ทุกการแก้ไขบันทึกค่าเดิมไว้ใน “ประวัติการแก้ไข”
- ทุกฉบับที่ลงนามมีรหัส SHA-256 ครอบคลุมข้อความรายการ คำตอบ ความคิดเห็น และลายเซ็น หากมีการเปลี่ยนแปลงหลังลงนาม
  หน้าผลการวิเคราะห์จะแจ้งเตือน และสามารถ “ส่งคืนให้แก้ไข” เพื่อให้ผู้เชี่ยวชาญยืนยันและลงนามใหม่ได้

## โครงสร้างโปรเจกต์

```
server.js            API และเส้นทางหน้าเว็บ
lib/db.js            ฐานข้อมูล SQLite และการนำเข้าข้อมูลตั้งต้น
lib/stats.js         การคำนวณ IOC / x̄ / S.D.
lib/export.js        ส่งออก Word / Excel
public/              หน้าผู้ดูแล (admin) และหน้าผู้เชี่ยวชาญ (expert) + แผ่นลงลายมือชื่อ
seed/                ข้อมูลแบบประเมินที่ดึงจาก Tool-research/*.docx
test/                ชุดทดสอบการคำนวณ
```

หมายเหตุ: ข้อความรายการในชุดที่ 3 (ข้อ 1, 3, 5, …, 13) ถูกตัดด้วย “…” ตั้งแต่ไฟล์ต้นฉบับ .docx — แก้ไขให้ครบได้ที่แท็บ “แก้ไขแบบประเมิน”
